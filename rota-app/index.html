Android phone

⬇ Download the app (1.3 MB)

For Android 7 or newer. Version 1.0 · updates come inside the app automatically – you install this only once.

How to install / कैसे इंस्टॉल करें

  1. Tap “Download the app”. If Chrome asks, tap Download again.“Download the app” दबाएँ। Chrome पूछे तो फिर से Download दबाएँ।
  2. Tap “Open” at the bottom of the screen (or open StaffRota.apk from Downloads / Files).नीचे “Open” दबाएँ (या Files → Downloads में StaffRota.apk खोलें)।
  3. If the phone says “For your security, your phone is not allowed to install unknown apps”: tap Settings → turn on Allow from this source → go back.अगर “unknown apps” वाला संदेश आए: Settings दबाएँ → “Allow from this source” चालू करें → वापस आएँ।
  4. Tap Install. If Google Play Protect warns about an unknown app, tap More details → Install anyway. This is our company app.Install दबाएँ। Play Protect चेतावनी दे तो “More details → Install anyway” दबाएँ – यह हमारी कंपनी का ऐप है।
  5. Open Staff Rota and sign in with your name and PIN as usual.Staff Rota खोलें और अपने नाम व PIN से लॉग-इन करें।
If you had downloaded “base.apk” earlier, delete that file – use this one instead. An old Staff Rota icon added from Chrome can be removed after installing.पहले डाउनलोड की “base.apk” फ़ाइल हटा दें – यही ऐप इस्तेमाल करें। पहले से Chrome वाला Staff Rota आइकन है तो नया ऐप इंस्टॉल करने के बाद पुराना हटा सकते हैं।
